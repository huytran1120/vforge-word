Trình soạn thảo văn bản cho

Trình soạn thảo văn bản hiện đại, siêu nhẹ, viết bằng Rust. Trải nghiệm Ribbon quen thuộc của Word, đọc/ghi định dạng DOCX & PDF, tối ưu hóa trên GPU với tốc độ tức thì và tích hợp sẵn MCP dành cho AI Agent.

🇻🇳

Việt hóa toàn diện & Mặc định sẵn

Không cần tinh chỉnh phức tạp: hơn 3.700 mục dịch thuật từ menu, thanh công cụ, các bảng hội thoại, thông báo hệ thống và phím tắt đã được Việt hóa tự nhiên và chuẩn xác ngay khi mở app.

⚡

Dàn trang 1.4 ms

Cơ chế cached paragraph layout thông minh giúp việc gõ phím trên tài liệu dài gần 200 trang chỉ mất khoảng 1.4 ms để tính toán lại toàn bộ trang.

🦀

100% Thuần Rust trên GPU

Không sử dụng Electron hay Tauri. Ứng dụng render trực tiếp bằng GPU thông qua egui + wgpu, khởi động tức thì và tiêu tốn cực ít bộ nhớ RAM.

🤖

Tích hợp sẵn MCP cho AI Agent

Mọi thao tác đều có ID lệnh rõ ràng. Cho phép các AI Coding Assistant (Antigravity, Claude, Gemini) kết nối qua Model Context Protocol để đọc, sửa và kiểm tra tài liệu tự động.

📄

Tương thích đa định dạng

Đọc & ghi chuẩn .docx (OOXML), mở file .doc cũ, xuất PDF vector sắc nét cùng khả năng nhập/xuất Markdown, LaTeX, ODT, RTF và HTML linh hoạt.

Cài đặt & Khởi chạy

Chạy thử nghiệm trên máy của bạn

$git clone https://github.com/huytran1120/vforge-word.git
$cd vforge-word
# Khởi chạy ứng dụng với tài liệu mẫu
$cargo run --release --bin vforge-word -- --sample
# Hoặc mở một tài liệu Word bất kỳ
$cargo run --release --bin vforge-word -- baocao.docx
# Chuyển đổi định dạng tệp siêu tốc
$vforge-word-cli convert baocao.docx baocao.pdf
# Trích xuất nội dung văn bản thuần
$vforge-word-cli text baocao.docx
# Kiểm tra cấu trúc tài liệu dưới dạng JSON
$vforge-word-cli inspect baocao.docx
# Kết nối Claude Desktop hoặc Antigravity qua MCP
$claude mcp add vforge-word -- vforge-word-cli mcp
# Hoặc điều khiển cửa sổ app đang mở qua cổng socket
$vforge-word --control 7981 &
$claude mcp add vforge-app -- vforge-word-cli mcp --connect 127.0.0.1:7981
